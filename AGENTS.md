# nedogon-site — правила для всех агентов (GPT, Claude и др.)

Сайт стримерши **NEDOGONPOLYA** — https://www.twitch.tv/nedogonpolya — на домене **nedogon-polya.ru**.

## Главное
- **Хостинг — GitHub Pages**, ветка `main`, корень репозитория. Файл `CNAME` с доменом не удалять.
- **Только статичный сайт**: HTML, CSS, JS. Без сервера, без сборки, которую Pages не выполнит
  (если нужен сборщик — собирать в GitHub Actions и публиковать результат).
- **Сайт должен открываться в России без VPN.** Не подключать ресурсы, которые в РФ блокируются
  или тормозят: Google Fonts допустимы, но всегда с запасным системным шрифтом; без внешних аналитик,
  без встраиваний Instagram/YouTube в iframe на первом экране — только ссылки.
- Вес первой загрузки — небольшой: картинки сжаты (WebP/AVIF), видео — только по клику.

## Содержание — только публичное
Брать информацию только из открытого профиля канала: описание, игры, ссылки на соцсети, донат, магазин,
почта для сотрудничества. **Никаких личных данных** сверх того, что она сама публикует.
Фото, логотип и фирменные цвета — только с её разрешения; до этого — заглушки.
Сайт показывается стримерше до запуска; без её согласия не выдавать его за официальный.

## Дизайн
Свой, не шаблонный, тёмная тема, отлично на телефоне. Без «нейрослопа»:
без Inter по умолчанию, фиолетовых градиентов, эмодзи вместо иконок, трёх одинаковых карточек,
стекла и свечения без причины, одинаковой анимации у всех блоков, текстов-заглушек.

## Как работать
- **Пушить прямо в `main`** — это и есть публикация: GitHub Pages выкладывает сайт на nedogon-polya.ru
  примерно через минуту. Отдельные ветки и Pull Request не нужны.
- Перед работой всегда `git pull origin main` — в репозиторий пишут и GPT, и Claude. Чужое не затирать.
- Сообщение коммита начинается с `[GPT]` или `[Claude]`.
- Сломалось — `git revert`, а не удаление истории. `push --force` в `main` запрещён.
- Никаких ключей, токенов и паролей в репозитории.

## Исследования о Полине — не в репозиторий
Репозиторий публичный. Хронологию поездок с датами, семью, города проживания, жильё и свежие места
сюда не класть: это превращается в карту её перемещений. Рабочие заметки лежат на сервере de
в `/root/private/nedogon-research/`. На сайт — только страна и год поездки, без семьи и точных дат.
