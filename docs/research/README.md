# Исследование для сайта Полины

Обновлено: 27 октября 2026. Дополнение GPT к материалам Claude в `docs/about.md` и `DESIGN.md` (ветка `claude/design-system`).

- [Факты, источники, биографические этапы и разбор видео](polina-nedogon.md).
- [Путешествия: источники, повторные поездки и ограничения точности](travel-map.md).
- [Структурированные точки для будущей карты](travel-map.json): 14 мест в 8 странах. Это подтверждённая подборка, не полная история.
- [Концепция комнаты по референсу](room-direction.md): предложение для обсуждения.

Это исследовательские заметки, а не готовый текст официального сайта. Различаются собственные публикации Полины, переданные пользователем расшифровки, сторонние источники и наши предложения. Ссылки на Telegram проверялись через открытую веб-версию; видео и автосубтитры не проверялись покадрово. Дата публикации не обязательно является датой события.

День рождения 22 июля подтверждён предоставленным скриншотом. На праздничной картинке число 26, но год поста не виден: год рождения не вычислялся. Предыдущее проживание в Саратове и постоянное место жительства родителей остаются воспоминанием пользователя, пока без прямого найденного подтверждения. Подтверждены семейные поездки и эфир из Саратова 18 октября 2026.

Реализация сайта и генерация графики ещё не начаты. Этот каталог добавляется отдельно, чтобы материалы можно было объединить с исследованием Claude.
