# Карточки стран: подключение материалов Claude

GPT отвечает за `assets/atlas.js`, `atlas-globe.js`, `atlas-math.js`, `atlas.css` и разметку глобуса. Контент стран хранится отдельно; изменение истории не требует правки Three.js.

В текущей версии уже подключён `content/countries/cards.json`: редакционная адаптация шести Markdown-карточек Claude, с историями и тремя выбранными моментами на страну. Исходные Markdown-файлы сохранены. Для Турции и России используются встроенные короткие истории.

## Быстрое подключение

Создать `content/countries/index.json` с массивом `countries`. Затем добавить в `head` главной страницы:

```html
<meta name="country-content" content="content/countries/index.json">
```

Контроллер загрузит файл и заменит только редакционные поля. Если файл временно недоступен или часть данных некорректна, остаются встроенные истории из `assets/atlas-data.js`. Пока файл не готов, метатег не нужен и лишние запросы не отправляются.

```json
{
  "countries": [
    {
      "id": "id",
      "chapter": "Бали",
      "title": "Короткий выразительный заголовок",
      "intro": "Вступление из одного-двух предложений.",
      "story": ["Первый абзац по проверенным материалам.", "Второй абзац."],
      "tags": ["IRL", "Путешествие"],
      "images": [
        {
          "src": "assets/countries/id.webp",
          "alt": "Описание того, что действительно видно на фотографии",
          "caption": "Вид страны · Unsplash",
          "role": "scenery"
        }
      ],
      "sources": [
        {"label": "Смотреть фрагмент", "url": "https://www.youtube.com/watch?v=qgsX30zvU-0&t=48s"}
      ]
    }
  ]
}
```

Коды `id`: `id` Индонезия, `ae` ОАЭ, `in` Индия, `th` Таиланд, `mv` Мальдивы, `vn` Вьетнам, `tr` Турция, `ru` Россия. Альтернатива — поле `code` с ISO-кодом верхнего регистра.

Все поля, кроме идентификатора, можно опустить: тогда сохраняется встроенное значение. Для изображений используются локальные пути в `assets/` или `content/`, форматы WebP/JPEG/PNG. Желательно 2–6 изображений на страну. Роли: `personal` — личное фото Полины, `video` — кадр её видео, `scenery` — иллюстративный пейзаж. Пейзаж не выдавать за доказательство посещения изображённой достопримечательности. Ссылки — только HTTPS. Строки выводятся как текст, HTML не исполняется.

Дополнительное поле `moments`: массив объектов `{ "time": "03:41", "title": "Название эпизода", "url": "https://..." }`. Вместо времени можно указать `ПОСТ`, `АЛЬБОМ` или `ВИДЕО`. Этот блок показывается отдельным списком перед первоисточниками.

На сайт попадают страна и год поездки. Не добавлять сюда семью, жильё, свежие места и подробную хронологию перемещений. Рабочие подробные исследования оставлять в приватном хранилище согласно AGENTS.md.

## Что уже работает

- Восемь стран вместо списка отдельных городов.
- Выбор по контуру страны, по увеличенной области метки или по кнопке списка. Мальдивы слишком малы для карты Natural Earth 110m, поэтому выбираются меткой или списком.
- Движение камеры, остановка вращения на время чтения и возврат прежнего ракурса после закрытия.
- Правая диалоговая панель, полноэкранная на телефоне; Escape, закрытие по фону, клавиатурные стрелки и свайп фотографий.
- Анимированная стопка фотографий, счётчик и переключатели. Подпись для каждого изображения.
- Страна/год, короткая история, темы, первоисточники и ссылка для открытия той же карточки.
- Поддержка системной настройки уменьшения движения и существующей кнопки анимаций.
- Истории доступны списком, даже если WebGL не загрузился.

Пейзажи и лицензии: `assets/countries/credits.json`. Границы: выделенные страны из world-atlas 2.0.2, Natural Earth 110m; лицензия `vendor/LICENSE-world-atlas.txt`. Это условная географическая визуализация, не точная навигационная карта.
